🇧🇩 Timeline Editor

Add, edit, reorder and photograph the moments in Isham’s story. Export when done, then commit the files.

How to publish your changes

  1. Add / edit moments above. For each photo, click Choose photo — the editor renames it to a tidy filename that lives in the images/ folder.
  2. Click Download new photos. Move the downloaded image files into this project’s images/ folder.
  3. Click Download timeline.json and replace the existing timeline.json in the project root.
  4. Commit & push both the new images and timeline.json to the claude/timeline-cms-photo-upload-2vff3v branch. GitHub Pages redeploys automatically.

Tip: this editor runs entirely in your browser — nothing is uploaded anywhere. Open it locally, or visit /admin.html on the live site.
